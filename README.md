# Interactive Valentine Card

A customizable interactive Valentine's Day card built with HTML, CSS and JavaScript.

The project includes an animated card layout, custom text, image, audio and video support, and a simple popup interface.

## Features

- Interactive Valentine card design
- Custom cover image
- Custom message
- Audio playback
- Video playback
- Popup window
- Responsive layout
- Simple customization
- No external frameworks required

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Customization

The template can be easily customized.

Change the cover image

Replace:
cover.jpg with your own image.

Change the message

Open index.html and edit the text inside the card.

Change the audio

Replace:
sample-audio.mp3 with your own audio file.

The audio source is defined in index.html:
<source src="sample-audio.mp3" type="audio/mpeg">

Change the video

Replace:
sample-video.mp4 with your own video.

The video source is defined in index.html:
<source src="sample-video.mp4" type="video/mp4">

Change the design

Colors, spacing, animations, positioning and other visual elements can be modified inside:
style.css

## Purpose

This project was created as a reusable template for making personalized interactive greeting cards.
Users can replace the default text, image, audio and video with their own content without changing the overall structure of the project.
